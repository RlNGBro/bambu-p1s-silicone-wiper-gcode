## 实际预设已经对齐

已只读核对 `本地自定义P1S预设`：保存的开始为r6、结束为r5、材料丝更换为r5。此前读取的 `另一份旧预设` 是另一份旧预设，不作为这次现象的诊断依据。没有修改用户预设，仅生成输出文件；替换后需要重新切片。

## 开始阶段的三个现象

| 现象 | 结论与处理 |
|---|---|
| 初始进料前去切刀附近再返回 | 官方及用户原版M620/T初始选料流程就有X20/Y50、Y-3，再返回的路线；保留此材料准备过程与已经确认的逐轴接近方式。 |
| AMS在后部进料时突然前移Y | r6中助手新增了T后X54→Y245→Y265；若T已经回到后部，会多走20mm前移再返回。r7删除Y245，恢复X54→Y265直接返回；不据此推断固件内部所有动作。 |
| 190°C擦后继续冷却时渗料、等待点在擦嘴边缘 | r6在X70等待，190°C四次完整擦拭之后还需继续冷却，140°C后只有退出扫过。r7改用官方初始冲洗位置X54/Y265等待，并把原四次往返拆成190°C一次＋140°C后三次。 |

### 开始 r7 顺序

1. 原较高温度的第一组四次硅胶扫动保留；显式回抽合计仍为1mm。
2. 回到官方初始冲洗位置 **X54/Y265**，M400；P1满速，等待190°C，再保留原15秒停顿。
3. 到X70，做一次 **X70→X100→X70** 温擦。
4. 再回 **X54/Y265** 并M400，在这里等到140°C，避免把擦嘴端点当成持续漏料的等待位置。
5. 到X70，做三次 **X70→X100→X70** 最终清理。
6. 经X100、X165、Y256退出，再进入正式调平。低温段无新增E动作，引料前仍补E2。

原第二组四次重分为1+3，总往返数不增加；新增X54往返属于冲洗点定位。每次完整擦拭首段由X70朝X100向外。粗Z归零仍在这几组之前。

用户确认结束退料后190°C不再流料，但开始装料后190→140°C仍流料，两种状态不能等同。140°C仍是原调平前目标，不保证残料能被硅胶轻易擦掉；最终三次属于针对冷却期间新残料的试调，新版效果未验证。本次没有加大回抽或另选未经依据的更低温度。

## 结束 r7 等待点及方向

旧结束r5在等温前保留了退料后X100快速横扫，第一擦又从X100向X70，和用户的实机反馈吻合。已删除这次提前外移。

当前顺序：切料退料 → 返回X65/Y265 → M621/M400 → 明确X54/Y265并等待运动完成 → P1满速等190°C、停15秒 → 到X70 → `(X70→X100→X70)×3` → 单独向外到X100停靠 → M400、关闭喷嘴/P1。

等温位置采用官方排料的X54/Y265，不再把X70或X100泛称废料口内。最终XY仍为X100/Y265。擦嘴计数是三次完整往返（六段）加一次向外停靠；擦嘴前还有一次X54→X70接近动作，不把定位移动混算成第四个往返。

回程动作仍存在，残料是否完全掉入废料口、是否被气流或回程带出，需要实机观察，不能由静态坐标保证。

## 保留的其他行为

- 后部去切刀逐轴路线：`X165/Y265 → X165/Y256 → X165/Y50 → X20/Y50 → X20/Y-3`。内部固件切料动作不改。
- 后部横移依据为官方Y265固定时到X165，再到Y256；等待X54依据为官方开始模板E50冲洗之前的显式位置，不是从照片猜测孔中心。
- 结束P2/P3同步运行约60秒，前35秒热床保持，随后下降；15秒等温稳定时间独立于风扇60秒。最终Z分支、电机电流等保留。
- 正常AMS材料丝更换r5、延时摄影r4本轮不变。
- 手动暂停恢复和AMS同槽缺料补料后继续保持设备内部逻辑，不追加擦嘴。
- 现有引料线低速起线、P1/P2时序、E2补料和无负Z硬擦设置保留。
