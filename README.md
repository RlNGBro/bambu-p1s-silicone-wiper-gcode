# P1S 硅胶擦嘴 G-code

用于记录拓竹P1S 0.4喷嘴搭配后部附加硅胶擦嘴件的代码调整，包含初始原版、初始修改版与当前最新版。README和操作说明使用中文。

**当前发布：v0.1.0 预发布。** 最新版可下载并导入切片器；已做模板静态检查，尚未完成最新版完整实机验收。历史打印反馈只覆盖部分较旧版本，不把静态通过称为防撞或擦净保证。

## 安装到Bambu Studio

以P1S 0.4打印机预设另存副本，打开打印机设置的机器G-code页面，把文件**完整内容**替换到对应字段，再保存并重新切片：

| 文件 | 字段 |
|---|---|
| latest/machine_start.gcode | 机器开始G-code |
| latest/machine_end.gcode | 机器结束G-code |
| latest/change_filament.gcode | 材料丝更换G-code |
| latest/timelapse.gcode | 延时摄影G-code |

模板里的大括号和方括号是切片变量，不能把文件作为已展开的运动代码直接发送打印机。暂停和换层字段不需要替换。已有切片文件不会随预设编辑自动更新，必须重新切片。

## 当前行为

- 开始仍保留官方进料前前往切刀附近再返回的准备流程；删除T初始选料后新增的Y245前后绕行，恢复X54→Y265。
- 后部等温采用官方初始冲洗位置X54/Y265，避免把X70擦嘴端点或X100外端当作排料等待点。
- 开始保留较高温度第一组四次扫动；原第二组四个往返重新分成190°C一次与冷却到140°C后三次。两段冷却都回X54等待；回抽合计1mm，引料前补E2，没有新增低温挤出。
- 引料线前关闭P1/P2，前20mm以15mm/s起线，其余主要横线30mm/s。恢复Z参考与ABL流程，禁用负Z硬擦。
- 结束切料退料后取消提前扫到X100；回X54/Y265等190°C并停15秒，接近X70后执行三次X70→X100→X70，首段向外，再单独向外停X100/Y265。三次往返和停靠动作分别计数。
- 开始、结束、计划内换料的切刀接近路线逐轴执行：X165/Y265→Y256→Y50→X20→Y-3；先离开后部再向左。
- 正常多色换料保留官方冲洗温度、挤出量、回抽补偿及完整擦料/甩料序列。手动暂停恢复、AMS同槽补料恢复保持固件内部逻辑，不追加擦嘴。
- 结束P2/P3同步运行约60秒，前35秒保持热床，随后下降，运动标称时间计入60秒。加减速和指令开销使实机时间可能略有差异。
- 最终XY为X100/Y265；最高打印Z小于150时最终Z=H+98，150到247.5时Z248，超过247.5时Z250。

## 适用范围与真实验证状态

基线为Bambu Studio 2.8.2.61、P1S 0.4、PETG与BIQU Glacier。不能据此推断其他喷嘴、材料、擦嘴件和固件均兼容。用户反馈结束退料后190°C不再渗料，但开始装料后190→140°C仍会渗料；因此不能把190°C当成普适止料温度。140°C后三次清理是试调，是否容易擦净尚未确认。

X54/Y265等待点和Y265下横移至X165有官方模板的显式坐标依据；新增逐轴折线、加装件净空、气流导致残料飞出和回程带料均未实测验证。Z封顶250不能给满高模型创造额外净空。最新r7的清理与掉料效果仍待验证。

## 离线检查

安装Node.js后在仓库根目录运行：

```powershell
node scripts/check-start-end.mjs
node scripts/check-ams-timelapse.mjs
```

检查包括模板块配对、等待位置和顺序、无低温E动作、擦拭次数、切刀逐轴顺序、7组结束高度/风扇计时、10组AMS场景与2种摄影模式。脚本只做静态展开和约束检查，不调用打印机，也不替代Bambu模板解析器。
